# بوم دکور — نسخه HTML/CSS/JavaScript خالص

این پروژه React نیست و هیچ پکیج یا build step لازم ندارد. برای GitHub Pages آماده شده است.

## انتشار
1. این ZIP را استخراج کنید.
2. همه فایل‌ها و پوشه‌های داخل آن (به‌ویژه `index.html`، `style.css`، `app.js` و `images`) را در ریشه Repository به نام `BOOM-DECOR` آپلود کنید.
3. در GitHub وارد Settings → Pages شوید.
4. در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
5. Branch را روی `main` و Folder را روی `/ (root)` بگذارید و Save کنید.
6. چند دقیقه بعد سایت از آدرس GitHub Pages نمایش داده می‌شود.

## امکانات
صفحه اصلی، دسته‌بندی‌ها، فروشگاه، جستجو، فیلتر دسته‌بندی، مرتب‌سازی قیمت، صفحه محصول، سبد خرید با ذخیره در مرورگر، علاقه‌مندی‌ها، تسویه‌حساب نمایشی، حساب کاربری نمایشی، تماس با ما، درباره ما، مجله و محاسبه‌گر متراژ.

## توجه
این یک وب‌سایت استاتیک سمت مرورگر است. پرداخت آنلاین، ثبت سفارش سمت سرور، موجودی زنده، حساب کاربری واقعی و پنل مدیریت ندارد. اطلاعات سبد و علاقه‌مندی‌ها در localStorage همان مرورگر ذخیره می‌شود.

# بوم دکور | Boom Decor Store

فروشگاه اینترنتی فارسی و راست‌چین برای فروش قرنیز، پارکت، لمینت و ابزار پلی‌استایرن.

## تکنولوژی‌ها
- React
- Vite
- CSS (Responsive / RTL)
- Lucide React Icons

## اجرا در سیستم
```bash
npm install
npm run dev
```

برای ساخت نسخه production:
```bash
npm run build
npm run preview
```

## انتشار در GitHub
1. یک Repository جدید در GitHub بسازید.
2. فایل ZIP را استخراج کنید.
3. تمام محتویات پوشه را در Repository قرار دهید.
4. Commit و Push کنید.

## انتشار رایگان با GitHub Pages
برای دیپلوی ساده، می‌توانید از Vercel یا Netlify استفاده کنید. در صورت استفاده از GitHub Pages باید `base` در `vite.config.js` متناسب با نام Repository تنظیم شود.

## صفحات پیاده‌سازی‌شده
- صفحه اصلی
- فروشگاه و دسته‌بندی‌ها
- جستجو، فیلتر قیمت و مرتب‌سازی
- جزئیات محصول
- سبد خرید با تغییر تعداد و حذف محصول
- تسویه حساب (دموی فرانت‌اند)
- حساب کاربری (دموی فرانت‌اند)
- علاقه‌مندی‌ها
- مجله و صفحه مقاله
- درباره ما و تماس با ما
- سوالات متداول، ارسال، پیگیری سفارش و مرجوعی

## تصاویر
تصاویر اختصاصی پروژه در `public/images` قرار دارند و قابل جایگزینی هستند.

## نکته مهم
این نسخه Front-end است. برای فروش واقعی باید بک‌اند، دیتابیس، درگاه پرداخت، احراز هویت، پنل مدیریت و سرویس ارسال به آن متصل شوند. فرم تسویه حساب در این نسخه صرفاً نمایشی است و پرداخت واقعی انجام نمی‌دهد.

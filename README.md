# بوم دکور | فروشگاه آنلاین دکوراسیون داخلی

نمونه‌کار مفهومی بازطراحی فروشگاه بوم دکور با رابط فارسی و راست‌چین (RTL).

## دسته‌بندی‌های اصلی
- پارکت و لمینت
- قرنیز
- ابزار و محصولات پلی‌استایرن

## امکانات نسخه نمایشی
- طراحی واکنش‌گرا برای دسکتاپ و موبایل
- صفحه اصلی و دسته‌بندی‌های تصویری
- جستجو، فیلتر دسته‌بندی و مرتب‌سازی قیمت
- کارت محصول و سبد خرید نمایشی
- متادیتای پایه SEO و داده ساختاریافته Store

## اجرا
فایل `index.html` را در مرورگر باز کنید یا از افزونه Live Server در VS Code استفاده کنید.

## انتشار در GitHub Pages
1. یک مخزن عمومی با نام `boom-decor-store` بسازید.
2. محتویات این پوشه را در ریشه مخزن قرار دهید.
3. در Settings → Pages، گزینه Deploy from a branch را انتخاب کنید.
4. شاخه `main` و پوشه `/root` را ذخیره کنید.

## مواردی که پیش از استفاده واقعی باید تکمیل شوند
- اطلاعات واقعی، قیمت، تصاویر، موجودی، برندها و مشخصات محصولات از کارفرما دریافت و جایگزین شوند.
- تصاویر فعلی صرفاً تصاویر نمونه دکوراسیون هستند و عکس واقعی محصولات نیستند.
- پرداخت آنلاین، ثبت سفارش، حساب کاربری و پنل مدیریت در این نسخه پیاده‌سازی نشده‌اند و به بک‌اند و اتصال امن درگاه نیاز دارند.
- قیمت‌های نمایش داده‌شده فرضی‌اند؛ واحد فروش و قیمت نهایی هر محصول باید تأیید شود.
- canonical و اطلاعات SEO باید پس از تعیین دامنه و محتوای نهایی بازبینی شوند.

## فایل‌ها
- `index.html` ساختار صفحه و SEO
- `style.css` طراحی و واکنش‌گرایی
- `app.js` داده نمونه، فیلتر و سبد خرید
